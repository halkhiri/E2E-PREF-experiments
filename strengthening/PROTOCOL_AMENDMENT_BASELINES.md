# Baseline fidelity corrections before test access

2026-09-29. During implementation review, before any test evaluation, the common sequence-prefix sampler was found to omit each user's first two training interactions as positive labels. Sequence encoders still observe these items in the history, whereas a static BPR model receives only user/item labels. BPR is therefore corrected to sample positives uniformly from the user's entire training partition and negatives outside that entire training-positive set. It retains one update example per user per epoch, 31 negatives, 50 epochs and the same three learning-rate trials. Both the architecture and pairwise objective remain unchanged. The other learned models continue to share the exact prefix examples. Accordingly, the experiment matches example counts and search opportunities, not the same labels across all model families.

The first three MovieLens BPR validation trials used the sequence sampler. They were archived without any test evaluation and rerun with the corrected standard sampler. These preliminary trials remain documented separately and are not combined with the final BPR results. Correction is motivated by baseline data exposure rather than test outcomes. source/baseline_plan.py and the updated parallel runner implement the final sampler.

## SASRec sequence training

The initial shared-prefix SASRec adapter is replaced, before test evaluation, by a source-informed implementation of the original training structure: left-padded sequences, all nonpadding next-item positions in each user’s final 30 training transitions, one uniform negative per positive position excluding all training positives, Xavier initialization, and Adam with beta2 = 0.98. The model retains two 32-dimensional blocks, one attention head and dropout 0.2. Model selection uses the common three-rate grid and 50 epochs. This supplies 24,764 positive positions per MovieLens epoch and 4,529 per Amazon epoch, whereas each E2E-PREF variant and BPR uses one example per user per epoch. The study therefore equalizes search opportunities and per-user batch/epoch budgets, not positive-pair counts or FLOPs. Original TensorFlow code is ported to PyTorch; exact official benchmark reproduction is not claimed.

Three preliminary MovieLens SASRec validation trials with shared-prefix training were archived and rerun. Together with BPR, six preliminary validation-only trials are separate from the206 fitting runs in the final design. No test result was accessed before these corrections. source/sasrec_baseline.py implements the final baseline, and evaluation.py uses its left-padding adapter.
