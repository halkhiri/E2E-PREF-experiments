# Prospective strengthening protocol

Locked before new model training or test evaluation, 2026-09-29.

Datasets: (1) a fresh random sample of 1,000 MovieLens-20M users with at least ten positive ratings, excluding every user in the prior pilot; sampling seed 29092026; full supplied movie catalog. (2) Amazon 2014 Musical Instruments 5-core release, all users with at least five distinct ratings >=4; all items appearing in the released 5-core file form a static catalog. The Amazon eligibility threshold retains sufficient histories in this smaller independent domain. Remove duplicate user-item events retaining the earliest positive event. Reserve final positive for test, penultimate for validation, with timestamp/item-ID tie breaking. No global chronological availability claim. Neither test outcomes nor review text enter training/features/tuning. Amazon metadata uses product titles/categories and log1p(price), missing price zero; exclude sales ranks, review summaries, co-purchase links and review-derived features.

Models: unchanged E2E-PREF ranking-only core; remove graph message passing; replace temporal encoder by masked history mean; remove text feature input; remove candidate cross-attention while retaining product/sum scorer; joint auxiliary package; contrastive-only, temporal-only and semantic-only auxiliary objectives; BPR-MF; SASRec architecture port with original pointwise logistic objective. Popularity and cosine item-neighborhood controls. SASRec trained on same sampled prefixes and negatives (explicit adaptation, not original benchmark reproduction). All neural families: dimensions32/history30, batch128, 50epochs, LR grid .001/.003/.01; one independent tuning seed 501 selects LR and epoch using sampled validation NDCG@10 only. Repeat selected LR for five seeds 101–105, each checkpoint selected on validation. All ablations receive same search budget; fixed architecture except ablated component. Baseline/model-specific objectives retained. ItemKNN select k from20/50/100 using validation. Equal search trials and epoch/example budgets do not mean equal FLOPs. Record runtime/parameters and boundary selections.

Matched mechanism: shared 25epoch dot-product pretraining followed by25epochs joint or frozen continuation, identical initialization, training examples, learning rate (selected ranking-only LR), disabled encoder dropout in both branches. Final pretraining state shared. Both continuations validated separately. Five seeds. No extra continuation tuning claimed.

Primary evaluation: full eligible static catalog, paired NDCG@10 differences; secondary Recall@20, MRR and 100-item sampled ranking. Full candidate set for candidate attention, never independent chunk attention. All tuning completes before any new test evaluation. Archive all checkpoints/logs; no reruns selected for favorable test outcomes. Save per-user ranks, positive scores, candidates and hashes. Conditional seed/user crossed bootstrap (5,000 draws); exploratory ablation intervals with no claim of multiplicity-controlled significance. Main contrast joint minus frozen on two datasets. Report every planned variant including unfavorable results. User sampling, filtering and hyperparameter-grid limits disclosed.

This is a timestamped local analysis plan, not external preregistration.
